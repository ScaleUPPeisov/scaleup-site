# VYRON AI STUDIO WEB v0.3 — веб-пульт с Mac Bridge

## Состояние продукта на 12.11.2026
- Веб-сайт: `https://vyron-ai-studio-private.vercel.app`, закрыт Vercel Authentication для всех deployments.
- Панель: редактор, архив, каналы, генерация текста через AI, Lumean quote/order/status, FLUX изображения, экспорт.
- Подготовлены **реальные** браузерные кнопки «Рендер в ENDLUME на Mac», очередь задач в Supabase и чтение статусов.
- Mac Agent: Python без внешних библиотек, исходящий HTTPS, Supabase RLS, чтение VYRON mapping snapshot, загрузка разрешённых медиа URL, локальный ENDLUME inbox и проверка квитанции.
- ENDLUME bridge: отдельная feature-ветка `feature/studio-cloud-inbox-bridge` репозитория `ScaleUPPeisov/endlume-desktop`; production app не заменяется.
- Фактический запуск рендера на Mac пользователя и видео в 30 минут **пока не проверены**. Не называть это production-ready.

## Что запустить один раз
### 1. Supabase schema
В SQL Editor существующего Supabase проекта выполнить **по порядку**:
- `studio/sql/001_owner_tables.sql`
- `studio/sql/002_mac_queue.sql`

Они создают отдельные таблицы с RLS по владельцу, очередь с атомарным захватом, таблицу устройства и расширяют список каналов публичными ID. **Не затрагивают YouTube Keychain или данные VYRON**.

Не запускать от имени неизвестного проекта и не раскрывать service-role key. Перед миграцией сохранить schema backup.

### 2. Веб
Открыть сайт под собственным Vercel аккаунтом, затем войти в Supabase под тем же владельцем. Локальный режим (без входа в Supabase) остаётся доступным для черновиков, но **удалённую очередь не поддерживает**.
В настройках Vercel сервера (НЕ в браузере) можно указать:
- `GEMINI_API_KEY` / `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` для сценариев;
- `LUMEAN_API_KEY` и `LUMEAN_TEMPLATE_ID` для озвучки;
- `FAL_KEY` для изображений.

После добавления — повторно развернуть сайт. Ни один ключ не следует размещать в GitHub или чате.

### 3. ENDLUME на M1
Скачать **отдельную ветку** ENDLUME `feature/studio-cloud-inbox-bridge`. Запустить из папки исходников `BUILD_STUDIO_BRIDGE_M1.command`. Программа будет собрана как `ENDLUME Studio Bridge.app` на рабочем столе **без замены** установленного ENDLUME.

Не запускать одновременно исходный ENDLUME и Bridge: у них пока одинаковый Tauri bundle ID, значит общие данные очереди. Подписание и production updater не трогать.

### 4. Mac Agent
Из этой папки `studio/mac-agent` запустить `УСТАНОВИТЬ.command`. При установке Mac Agent авторизуется **своим** Supabase refresh token, сохранённым в закрытом файле прав `0600`, а не из VYRON. При необходимости отдельно настроить Lumean ключ с правами `orders.read` и `orders.download`.
Фоновая служба запускается при входе в macOS. Не требует проброса портов, Tailscale или статического IP. 
Проверка:
- `~/Documents/VYRON/State/mappings.json` — редактирует только VYRON; агент читает список имён/каналов, OAuth профиль ID не отправляется.
- `~/Movies/VYRON AI STUDIO/Bridge/endlume-heartbeat.json` — обновляет только новая сборка ENDLUME.
- `~/Movies/VYRON AI STUDIO/Projects/<project-uuid>/` — изображения и звук для задачи. Можно положить свои JPG/MP3 или скачать из Lumean и FLUX через агент.
- `~/Movies/VYRON AI STUDIO/Renders/<project-uuid>/` — итоговый MP4 после FFprobe.

### 5. Работа
Открыть сайт из любого браузера/сети → войти → создать проект → написать сценарий → получить и подтвердить озвучку → сгенерировать изображения → убедиться, что Mac и ENDLUME показаны как «в сети» → нажать «Рендер в ENDLUME» → дождаться подтверждённого результата.
Текущий модуль сохраняет MP4 на Mac. Автоматическая загрузка MP4 в облако, точный тайминг многосценной документалки и автопубликация в YouTube ещё НЕ реализованы.

## Безопасность и отказы
- Нет открытых локальных HTTP-портов и произвольных команд.
- Доступ Supabase — только owner RLS; один Mac атомарно забирает работу. После падения нет самовольного повторного рендера/списания.
- Перед Lumean и FLUX — отдельное подтверждение расхода.
- При ошибке рендера хранится текст ошибки и исходный проект. Успех — только по квитанции после ENDLUME FFprobe.
- Рекомендуемое восстановление: открыть проект, посмотреть статус задачи, проверить локальные материалы, затем повторить вручную.
- mac-agent можно отключить через `ОТКЛЮЧИТЬ_АГЕНТ.command`; авторизации YouTube и стабильный VYRON это не меняет.
- Не использовать сборки из этого PR как безусловно production-ready без физического теста.

## Испытания
- В Vercel: `npm run build` запускает Node.js API security tests и Python mac-agent unit tests.
- В ENDLUME GitHub Actions: macOS `cargo check` и изолированные Rust unit tests, без ключей подписи.
- До физического теста Mac M1/качественного ролика и включения SQL миграции интеграцию нужно считать **pre-release**.
