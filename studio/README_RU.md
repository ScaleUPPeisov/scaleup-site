# VYRON AI STUDIO WEB 0.2 — закрытая браузерная консоль

Это **не** готовый полностью автономный видеозавод. Реализована и развернута безопасная основа с настоящими API-маршрутами, но полноценная работа требует конфигурации владельца.

## Архитектура
- Приватный сайт: Vercel Authentication = all deployments; доступ только участникам проекта Vercel. **Никакого открытого доступа по IP**.
- Синхронизация: существующий Supabase Auth + `studio_v2_projects` и `studio_v2_channels`, RLS по `auth.uid()`.
- Фолбэк: локальные черновики в этом браузере, **без синхронизации**. Можно экспортировать резервную копию; после настройки БД — перенести локальные данные в облако.
- AI: `/api/ai`, Gemini/Anthropic/OpenAI; текст модели генерируется настоящим API, ответ и сведения об использовании сохраняются в Supabase/локальном режиме.
- Озвучка: `/api/voice`, бесплатная котировка Lumean; платный заказ требует подтверждения. Доступен реальный опрос статуса.
- Изображения: `/api/image`, FLUX schnell через fal queue; перед оплатой подтверждение; результат содержит внешний URL, который необходимо сохранять.
- Экспорт: JSON-манифест проекта с текстом, сценами и заданиями. Это не готовое MP4.
- ENDLUME/VYRON: **не интегрированы с сайтом**, стабильные desktop-версии не затрагиваются.

## Однократная настройка владельца
1. Открыть защищённый сайт в браузере: https://vyron-ai-studio-private.vercel.app, войти в Vercel.
2. Для облачной синхронизации открыть Supabase SQL Editor своего проекта и выполнить `sql/001_owner_tables.sql` один раз. Таблицы создаются отдельно и не затрагивают старую систему.
3. Войти в сайт с тем же Supabase-аккаунтом, что используется в существующей owner-control панели.
4. В Vercel → Project → Settings → Environment Variables задать **серверные** ключи (не вводить их в HTML и не передавать в чат):
   - один из `GEMINI_API_KEY`, `ANTHROPIC_API_KEY`, `OPENAI_API_KEY`; `AI_PROVIDER=auto` по умолчанию. При необходимости `GEMINI_MODEL`, `ANTHROPIC_MODEL`, `OPENAI_MODEL`.
   - `LUMEAN_API_KEY` и действительный UUID `LUMEAN_TEMPLATE_ID` (шаблон голоса и модели создаётся в Lumean).
   - `FAL_KEY` для изображений.
5. После изменения ключей сделать новый deployment (секреты применяются к новым функциям).
6. Открыть Настройки сайта: проверка здоровья покажет *реальную* доступность интеграций.

## Защита расходов
- API не вызываются при создании проекта.
- AI и FLUX требуют явного подтверждения; Lumean сначала даёт оценку токенов, затем требует отдельное подтверждение оплаты.
- Стоимости в рублях не выдумываются: счёт у провайдера остаётся источником истины.
- В API-маршрутах нет механизма бесконтрольного фонового массового заказа.
- Пароли, OAuth и ключи YouTube никогда не копируются в интерфейс сайта.

## Что ещё нужно до релиза «как часы»
- Автономный исполнитель для Mac M1, работающий через защищённую исходящую синхронизацию; Tauri/ENDLUME не имеют доступного публичного облачного API. Невозможно автоматически управлять выключенным Mac.
- Устойчивое хранение медиа (отдельный приватный bucket), повторная загрузка и проверка скачанных материалов; текущие URL генератора могут истечь.
- Перезапуск фоновых шагов, идемпотентность платных запросов, контроль лимитов, проверка статусов.
- Автоматический монтаж и техническая проверка FFprobe перед маркировкой завершения; публикация YouTube — только после согласия владельца.
- Надёжный биллинг через данные провайдеров и квоты.
- E2E-тест с реальными API-ключами и локальным Mac, без открытия секретов.

## Тесты
`npm test` проверяет 401 без авторизации на AI/voice/image/health, защиту от cross-origin POST и 400 при неверном JSON.
`npm run build` проверяет синтаксис всех API и браузерного модуля, затем запускает эти тесты и публикует файлы в public.

## Политика текущих продуктов
Стабильный VYRON 6.1.15 и его Keychain не изменяются. PR #22 с security hold и ключами подписи не трогаем. ENDLUME не запускается удалённо без отдельного безопасного агента.
