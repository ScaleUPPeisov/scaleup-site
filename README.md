# ENDLUME Windows Public Black-Box Audit

This branch is an isolated public black-box acceptance harness for already-published ENDLUME Windows binaries.

It contains no ENDLUME production source code, no private repository history, no customer data, no credentials, no signing keys, and no private tokens.

The workflow uses only anonymously accessible public release artifacts and independently verifies the expected artifact size and SHA-256 before any execution.
